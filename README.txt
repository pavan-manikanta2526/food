SPICE HAVEN — RESTAURANT WEBSITE
================================

Files
- index.html: page structure and content
- style.css: responsive layout and styling
- script.js: mobile navigation, menu filters, and demo reservation form

How to run
1. Extract the ZIP file.
2. Open index.html in a modern web browser.

Notes
- Built with HTML, CSS and vanilla JavaScript.
- Food photography and Google Fonts are loaded from online services, so an internet connection is needed for those assets.
- The reservation form is a front-end demo only. It does not send or store bookings.
- Replace the sample restaurant address, phone number, menu, prices and review text with your own details.
